The instrument

Every result is read against noise. A single model counts as better only if its OOF beats its strict twin by Gate 1. A blend leg counts only if adding it lifts the champion blend by more than 2 bootstrap SD (Gate 2). Public deltas under about 0.00015 are noise.

Progress over time

Dots are full-data single models, coloured by learner. Lines are the best OOF so far for singles and for blends; the dashed line is the best public score so far. Grey labels mark when each phase began.

OOF vs public

Each submitted run. The line is the least-squares fit; the band is ±1 public SD. Points inside the band can't be ranked by public score, which is why decisions use OOF.

Inside the champion

The legs of the current champion blend (rank mean), read from its manifest. Each leg sees the route in a different way, and that difference is why it earns a place.

Axes: what has been tried

Every run

Δ is OOF minus the strict twin's OOF, the one-key-changed baseline. Green clears Gate 1 (+0.00014). Red is worse by as much. Grey is inside the noise. Click a header to sort.

The feature pipeline

How a run turns raw columns into a prediction. Unsupervised features are computed once over train and test. Supervised encoders are fitted inside each CV fold so labels never leak. Highlighted chips are what the current champion's legs actually use.

Every technique, and whether it was tried

Coverage is read from every archived run config, so nothing here is claimed by hand. "Best Δ" counts only probes where the technique was the one key changed versus the twin. Not tried rows carry the reason they were skipped.

What each champion leg sees

Each blend leg is one way of seeing the data. Legs differ in whether they get the route profile, a teacher, and which columns are treated as categories. That difference is what the blend averages over.

Data at a glance

The competition data is synthetic, generated from a 130k-row airline survey (the "original"). There's no drift between train and test, so the adversarial AUC is about 0.5.

flight_distance is a route ID

Each dot is one of the 400 most common distances, plotted as its satisfaction rate. The line is the smooth trend over 50-mile bins. If distance were a plain magnitude, dots would sit within noise of the line. Many sit far off it (red: more than 3 SD), because each distance is really a route with its own passenger mix. This is the contest's biggest finding (+0.0016).

Satisfaction by age

The rate per age value (ages with 30 or more rows). It's a smooth curve, so age reads as a magnitude. The extra gain from age came only through CatBoost combinations like age × class.

Satisfaction by delay

Rate per delay bucket in minutes. Longer delays mean fewer satisfied passengers, but the effect is mild next to the ratings.

Satisfaction by survey rating

The rate for each rating level (0 = not answered). Darker cells are more satisfied. Dropping all 13 ratings costs 0.08 AUC (D2), so they carry most of the signal.

Categoricals: train vs original

The satisfaction rate per level in the competition data and in the original survey. They match closely: the generator copied the original's structure, which is why a teacher fit on the original helps.

What signal is left: residual χ²/df

For each column, this measures whether the model's errors still vary by value more than noise allows. About 1 means the column is fully used; above 1 means signal is left. Compare the A0 baseline with the champion.
